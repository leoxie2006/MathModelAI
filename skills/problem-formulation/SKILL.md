# 问题建模抽象

用于把模糊业务问题或竞赛题转化为可求解的数学模型。

## 步骤

1. 提取目标：明确需要优化、预测、分类、评价还是仿真。
2. 定义变量：区分决策变量、状态变量、外生参数和观测数据。
3. 写出约束：包含物理边界、业务规则、资源限制和数据可用性。
4. 建立指标：定义目标函数、损失函数或评价指标。
5. 管理假设：列出关键假设，并说明每条假设可能带来的偏差。
