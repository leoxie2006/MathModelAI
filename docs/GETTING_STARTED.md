# 快速开始

1. 配置 `config.yaml` 中的模型服务。
2. 启动服务：

```bash
./run.sh --http
```

3. 打开浏览器访问 `http://127.0.0.1:8080/`。
4. 在角色中选择「数学建模」，尝试输入一个建模问题。

示例问题：

```text
某工厂有三条产线和两类产品，已知单位利润、工时和材料约束，请建立利润最大化模型并给出求解思路。
```

后续开发建议优先改造这些位置：

- `agents/`：完善多代理职责。
- `skills/`：沉淀建模工作流。
- `tools/`：接入 Python、优化器、绘图和数据处理工具。
- `knowledge_base/`：增加常用模型和案例。
