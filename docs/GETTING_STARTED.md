# 快速开始

1. 配置 `config.yaml` 中的模型服务。
2. 启动服务：

```bash
./run.sh --http
```

3. 打开浏览器访问 `http://127.0.0.1:8080/`。
4. 新建项目，在项目详情的「工作空间」上传赛题附件、数据表或官方模板。
5. 在角色中选择「数学建模」，并绑定当前项目后输入建模问题。

示例问题：

```text
某工厂有三条产线和两类产品，已知单位利润、工时和材料约束，请建立利润最大化模型并给出求解思路。
```

后续开发建议优先改造这些位置：

- `agents/`：完善多代理职责。
- `docs/TEAM_AGENT_FRAMEWORK.md`：查看“竞赛队长 + 建模手 + 编程手 + 论文手”的三层协作框架。
- `docs/TODO.md`：查看后续完善路线图。
- `skills/`：沉淀建模工作流。
- `toolbox/`：接入 Python、优化器、绘图、数据处理和论文导出工具。
- `workspaces/{project_id}/`：每个项目的附件、数据、代码、输出和论文目录。该目录为运行时产物，默认不提交 git。
- `knowledge_base/`：增加常用模型和案例。
